## Rastreabilidade

- Adicionar aqui o link real do arquivo Figma somente depois de obter um resultado confirmado.
- Relacionar cada tela aprovada ao fluxo e à implementação correspondente.
- Identificar dados de exemplo como sintéticos e estados sem integração como protótipo.
- Aprovação visual não significa integração concluída. Captura de uma tela não significa que o fluxo inteiro passou nos testes.
- O repositório guarda requisitos, decisões, fontes e histórico local. O Figma guarda o artefato visual quando estiver conectado; não pressupor sincronização automática bidirecional.
